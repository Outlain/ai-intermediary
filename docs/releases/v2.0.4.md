# AI Intermediary v2.0.4

## Completed media and verified GPU cleanup

- Completed/imported media remains available while GPU release is pending. The
  dashboard distinguishes successful generation from an unverified cleanup,
  shows the latest release check and reports bounded retry status.
- The updated ComfyUI bridge observes native-worker flag consumption, successful
  model unload and subsequent cache cleanup. Proof is bound to the current
  process instance and cleanup request, and invalidated by new work or changed
  evidence. HTTP acknowledgment and an empty queue alone are not completion.
- `media.max_idle_torch_vram_mb` defaults to 128 MiB (0–256; 0 is strict zero).
  Nonzero residual allowance requires updated bridge proof, an empty model
  registry/queue and stable physical GPU/process checks. Older bridges keep
  strict-zero allocator checks.
- `media.max_idle_vram_mb` still defaults to 512 MiB. Existing physical limits
  are not silently increased. An explicitly verified post-unload baseline may
  justify a different setting; the two limits are independent.
- Cleanup gets at most three automatic recovery passes per process incident.
  Temporary history-read failures do not exhaust that budget; result discovery
  and import remain possible afterward. Generation is never replayed to recover
  cleanup, and manual pauses remain in effect.

## Upgrade

Use `ghcr.io/outlain/ai-intermediary:v2.0.4` and update **both** installed bridge
files (`__init__.py` and `bridge.py`) from this release. Updating the container
alone does not update an already-installed ComfyUI extension.

Pause inference, verify no active generation or queued backend work, preserve
the old bridge files, and restart ComfyUI at that safe boundary. Preserve the
existing Compose configuration, named volumes, settings, credentials, models,
outputs and service launch options. No new password or Python dependency is
required. See [bridge setup and update notes](https://github.com/Outlain/ai-intermediary/blob/v2.0.4/integrations/comfyui/README.md#verified-cleanup-and-small-residual-allocations)
and [media recovery](https://github.com/Outlain/ai-intermediary/blob/v2.0.4/docs/MEDIA_RECOVERY.md#completed-video-but-gpu-release-stays-pending).

## Validation and limits

Local validation: 515 JavaScript tests, 129 Python host/bridge/tooling tests,
publication checks and a Docker image build passed. Tests include bounded
residuals, unknown processes, stale samples, malformed/mismatched proof,
persisted output recovery, retry limits and media-to-chat handoff.

Hardware behavior still needs verification on the target GPU. This is not an
OOM cure or permission to overlap GPU jobs. It does not reset the GPU, restart
Ollama, restart ComfyUI automatically, or claim that small active allocations
are free cache. Native worker cleanup observations were checked against
ComfyUI v0.37.0; incompatible behavior fails closed.
